---
title: SDC components - Props
---

Props allow SDC components to define configurable inputs. Each prop can specify
its type, whether it's required, and provide example values.

Props can be used to:

- Insert content (text, images, etc.)
- Configure component appearance (colors, alignment, state)
- Control component behavior (animations, interactions)


Each prop can specify its type and the widget used when editing this prop.

## Prop types

1. **string**: A simple text input.
2. **number**: A numeric input.
3. **boolean**: A checkbox input.
4. **object**: A complex input that can contain multiple properties.
5. **array**: A list of items, each of which can be a string, number, or object.

## Widgets and formats

Canvas automatically selects appropriate input widgets based on prop configuration:

- **Boolean**: Rendered as checkboxes
- **String**: Multiple widget options available by specifying `format`, `$ref`, and other properties:
  - Text input
  - Textarea (with or without CKEditor)
  - Dropdown (using `enum` and `meta:enum` properties)
  - Date, time, duration pickers
  - Link picker with auto-completion
- **Number**: numeric input widgets:
  - Number input field
  - Dropdown with predefined values
- **Array**: Rendered as lists where users can add or remove items (not fully supported yet)

### Dropdown example

Using `enum` to create dropdown options. The optional `meta:enum` allows you to
customize display labels and enable translation capabilities:

```yaml
    test_string_enum:
      title: 'String - Enum'
      type: string
      enum:
        - foo
        - bar
      meta:enum:
        foo: Foo
        bar: Bar
```
