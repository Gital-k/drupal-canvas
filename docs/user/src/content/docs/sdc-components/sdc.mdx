Starting with Drupal 10.3, Single-Directory Components became part of Drupal
Core's render system. SDC components are a new way to create reusable components
in Drupal. Coupled to Drupal Canvas, the only limitation will be your
imagination ! Think BIG, think Canvas + SDC.

## What Is an SDC Component?

A SDC (Single Directory Component) is a reusable building block defined in code
using a `.component.yml` file, a Twig template, and optional CSS/JS.

Each SDC component can declare:
- Customizable content & settings inputs (props)
- Optional slots for additional nested components.

## How to use SDC in Canvas

1. SDC are listed in the **Library panel** under **Components**.
2. **Drag** them into the canvas, they render instantly as part of the page.
3. **Fill & set** their inputs aka props in the **Settings** in the right sidebar.
