## SWR

[SWR](https://swr.vercel.app/) is provided as a native package and can be
imported and used for general data fetching. Data returned will be shown in the
"Data Fetch" pane under the component preview.

```jsx
import useSWR from 'swr';

export default function Profile() {
  const { data, error, isLoading } = useSWR(
    'https://my-site.com/api/user',
    fetcher,
  );

  if (error) return <div>failed to load</div>;
  if (isLoading) return <div>loading...</div>;
  return <div>hello {data.name}!</div>;
}
```

## Drupal data

### Page and site data

You can access information about the current page with the `getPageData`
utility. Results can be viewed in the Data Fetch pane below the component
preview.

```js
import { getPageData } from 'drupal-canvas';
const { pageTitle, breadcrumbs } = getPageData();
```

You can also access site information with the `getSiteData` utility

```js
import { getSiteData } from 'drupal-canvas';
const { siteName } = getSiteData().branding;
```

### JSON:API

[drupal-canvas](https://www.npmjs.com/package/drupal-canvas) provides
[JSON:API client](https://www.npmjs.com/package/@drupal-api-client/json-api-client)
automatically configured with a baseUrl as well as
[deserialization](https://project.pages.drupalcode.org/api_client/jsonapi-tutorial/deserializing-data/).
[JSON:API module](https://www.drupal.org/docs/core-modules-and-themes/core-modules/jsonapi-module)
must be enabled to interface with this client.

The associated
[parameter helper package](https://project.pages.drupalcode.org/api_client/jsonapi-tutorial/parameters/#generating-query-strings-with-drupal-jsonapi-params)
is also provided as native package. 

```jsx
import useSWR from 'swr';
import { JsonApiClient } from 'drupal-canvas';
import { DrupalJsonApiParams } from 'drupal-jsonapi-params';
const client = new JsonApiClient();

export default function List() {
  const { data, error, isLoading } = useSWR(
    [
      'node--article',
      {
        queryString: new DrupalJsonApiParams()
          .addInclude(['field_tags'])
          .getQueryString(),
      },
    ],
    ([type, options]) => client.getCollection(type, options),
  );

  if (error) return 'An error has occurred.';
  if (isLoading) return 'Loading...';
  return (
    <ul>
      {data.map((article) => (
        <li key={article.id}>{article.title}</li>
      ))}
    </ul>
  );
}
```

You can override the `baseUrl` and any default options:

```js
const client = new JsonApiClient('https://drupal-api-demo.party', {
  serializer: undefined,
  cache: undefined,
});
```

<Aside type="tip">
  For local development outside Drupal Canvas, use
  [`@drupal-canvas/vite-plugin`](https://www.npmjs.com/package/@drupal-canvas/vite-plugin)
  to automatically provide necessary configuration based on environment variables.
</Aside>

<Aside>
  When working with code components outside Drupal Canvas you may need
  to configure CORS headers on your Drupal site to allow requests to JSON:API
  from your development environment.
</Aside>

### Helper utilities

Utility functions for working with JSON:API and core APIs are also provided in
the [`drupal-canvas`](https://www.npmjs.com/package/drupal-canvas) package.

### Examples

Given a node returned from `JSON:API`, return either the path alias or fall back
to /node/x path:

```jsx
import { getNodePath } from 'drupal-canvas';
const articles = data.map((article) => ({
  ...article,
  _path: getNodePath(article),
}));

// Sort menu items from jsonapi_menu_items module into a tree with additional
// _children and _hasSubmenu properties.
import { sortMenu } from 'drupal-canvas';
const { data } = useSWR(['menu_items', 'main'], ([type, resourceId]) =>
  client.getResource(type, resourceId),
);
const menu = sortMenu(data);
```

Using the [core linkset endpoint](https://www.drupal.org/docs/develop/decoupled-drupal/decoupled-menus/decoupled-menus-overview):

```jsx
import { sortLinksetMenu } from 'drupal-canvas';
const { data } = useSWR('/system/menu/main/linkset', async (url) => {
  const response = await fetch(url);
  return response.json();
});
const menu = sortLinksetMenu(data);
```
